# ADR-0015: 穴馬（7番人気以下）専用モデルへの分離は行わない

- Status: Rejected
- Date: 2026-08-02

## Context

`predict` の「堅実」「大穴」戦略がどちらもレース内win_prob最大馬（top1）を人気帯で振り分けているだけの実装のため、top1がたまたま穴馬だった日は両戦略が同一馬に収束してしまう（2026-08-02 クイーンS で実際に発生）。この収束が「モデルの穴馬に対する解像度不足」由来なら専用モデルで解消できるという仮説を、popularity>=7の行のみで学習したモデルと baseline（全馬学習）を比較して検証した。

## Decision

穴馬専用モデルは採用しない。baseline（全馬で学習・デフォルト）を維持する。

## Consequences

- 穴馬専用モデルは自分の得意分野（穴馬、popularity>=7の行）に対してすら baseline に負けた（win_logloss 0.09065→0.10282、win_brier 0.01610→0.01724）。学習行を絞ったことによるサンプル減少（-42%）が、人気馬側の豊富なサンプルから得られる汎化知識の喪失を上回った。
- 「堅実・大穴の収束」はモデルの精度問題ではなく、`output.py` の戦略選択ロジック（`_select_strategy_pick`）自体の構造的な問題と判明。対応方針は `todo.md` を参照。
