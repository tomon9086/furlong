# ADR-0035: 勝率の鋭さ（レース単位の温度）調整を採用しない

- Status: Rejected
- Date: 2026-10-17

## Context

人気帯別の較正（`python -m predictor.main calibration-by-popularity`）で、モデルの確率が全体に平らすぎ、人気薄を大きく過大評価している（13番人気以下の勝率は予測 2.0% に対し実際 0.43%、1番人気は予測 19.2% に対し実際 33.5%）と分かった。現行の勝率は「lambdarank の生スコア → 馬ごとの isotonic 較正 → レース内で合計1に割り戻し」で作っており、レースと無関係に馬ごとに確率へ変換する部分が平らさの原因かを確かめるため、V1: 現行を `p**gamma` で鋭くする、V2: isotonic を通さず生スコアのレース内 softmax に温度をかける、を比べた（係数は較正期間 10,677レースで推定、テスト期間 21,443レース、レース単位ペアード bootstrap、`python -m predictor.main compare-sharpness`）。

## Decision

勝率の作り方は現行のまま変えない。

## Consequences

- 推定した係数は V1 gamma=1.20・V2 k=1.14（どちらも鋭くする向き）だが、テスト期間では勝率の対数尤度が V1 +0.0029（CI [+0.0010, +0.0049]、有意に悪化）・V2 +0.0014（CI [−0.0007, +0.0034]、有意差なし）、3着内率の logloss は両方とも有意に悪化した。較正期間とテスト期間で最適な鋭さが違う。
- 人気帯別のずれはわずかに縮むだけ（13番人気以下の勝率の 実際/予測 が 0.22 → V1 0.27・V2 0.24）。
- 結論: 確率の平らさは確率の作り方ではなく、**市場が持っていてモデルに無い情報**による（確率の大きさ別には較正が取れているのに、同じ確率の馬でも人気がある馬のほうが実際によく来る）。較正では埋められず、情報（特徴量）を足す必要がある。オッズを特徴量に入れるかどうかは、モデルの役割（市場と独立した見立てか、市場込みの確率か）の判断次第で、別途検討する。
