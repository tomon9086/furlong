# ADR-0009: 7番人気以下タイの馬連・三連複・ワイドをEV戦略として採用しない

- Status: Rejected
- Date: 2026-05-26〜2026-08-02

## Context

[ADR-0007](./0007-distance-course-weight-jockey-change-features.md) 時点の単一split・EV閾値×人気帯×券種グリッド探索で、「EV≥2.0×4-6番人気×馬連（118.1%）」「EV≥1.0〜2.0×7番人気以下×馬連（132〜137%）」「EV≥3.0×7番人気以下×三連複（178%）」等、回収率100%超えの組み合わせが複数見つかっていた。「堅実」「大穴」戦略の軸重複を検討する過程でこれらが bootstrap CI 未検証のまま埋もれていたことが判明し、現行モデル（[ADR-0013](./0013-trainer-jockey-lifetime-win-rate.md) 時点）で walk-forward（5フォールド）プール bootstrap CI により再検証した。

## Decision

7番人気以下タイの馬連・三連複・ワイドをEVベット戦略として採用しない。「大穴」戦略は現状の単勝・EVフィルタなし設計のまま維持する。

## Consequences

- 再検証結果: 馬連48.7〜54.0%、三連複47.2〜54.1%、ワイド62.0〜70.1%（EV閾値1.0〜2.5全域）。CI上限の最大値も83.9%止まりで、全閾値・全券種で「有意>100%」は0件。
- 単一split・多重比較（複数券種×人気帯×閾値）の中から偶然良く見えた組み合わせを拾っていたと判断。「回収率は分散が大きく単一splitの点推定は信用できない」という教訓の典型例。
