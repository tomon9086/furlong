# ADR-0036: オッズなしモデルの勝ちモデルを lambdarank から Plackett-Luce（上位3頭）目的関数に切り替える

- Status: Accepted
- Date: 2026-10-17

## Context

現行の勝ちモデルは lambdarank（`label_gain` 線形）で学習し、生スコアを馬ごとに isotonic 較正してレース内で割り戻している。三連複・3着内の精度を上げる案C（3着内を直接学習）として、上位 K 頭の着順の Plackett-Luce 尤度を自作目的関数にした LightGBM（`predictor/pl_model.py`、出力はレース内 softmax、木の本数は較正期間の尤度で早期終了）を作り、現行と比べた（`python -m predictor.main compare-market-residual [--walkforward]`、全馬の単勝オッズがあり同着なしのレースに揃えて、レース単位ペアード bootstrap）。

## Decision

オッズを使わないモデルの勝ちモデルは、Plackett-Luce（上位3頭、P3）に切り替える。

## Consequences

- 標準 split（テスト 21,443レース）: P3 は現行比で勝率の対数尤度 −0.0153（CI [−0.0185, −0.0122]、有意に改善）、三連複対数尤度 −0.027（CI [−0.095, +0.009]）・3着内率の logloss +0.0005（CI [−0.0000, +0.0010]）は有意差なし。
- walk-forward（5フォールドプール。各フォールドの学習期間の最後の1割を較正・早期終了に使い、テスト期間には触れない）: P3 は勝率 −0.171・三連複 −0.979・3着内率 −0.0007 といずれも有意に改善。現行の三連複対数尤度が 5.85 と標準 split（4.84）より大きく悪いのは、isotonic 較正が一部の馬にほぼ0の確率を付けているためと推測される（未検証）。P3 にはこの問題が無い。
- 勝ち馬だけで学習した P1 は P3 より悪く（3着内率が有意に悪化）、2・3着まで学習することに意味がある。
- 人気薄の過大評価は残る（勝率の 実際/予測 は13番人気以下で 0.20）。これは ADR-0035 のとおり情報不足によるもので、目的関数では直らない。
- フォローアップ: 運用（`train`・`predict`・`output.py` の推奨）の勝ちモデルを P3 に切り替える。P3 は確率を直接出すので isotonic 較正は不要。複勝モデル（`place_prob`）は従来どおり残すが、三連複・3着内は P3 の Plackett-Luce から出す。
