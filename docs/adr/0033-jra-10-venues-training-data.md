# ADR-0033: JRA の学習データを4場から10場に拡張する

- Status: Accepted
- Date: 2026-10-16

## Context

1995〜2025年の JRA レースは、東京・中山・中京・京都の4場しか DB に無かった（2026年3月の一括投入時の別プロジェクトの設定由来。本来は「東京・中山・阪神・京都」の意図で、阪神のコードを取り違えていた）。残り6場（札幌・函館・福島・新潟・阪神・小倉）の約5.1万レースを補完したうえで、補完前の状態を再現した4場モデル（4場のレースだけで特徴量を計算し直す）と10場モデルを、テスト期間の4場のレースで比較した（`python -m predictor.main compare-venues`、レース単位ペアード bootstrap、n=10,000）。これまでの ADR はすべて4場のデータでの判定である。

## Decision

JRA の学習データは10場すべてを使う（`load_data(venues=JRA_VENUES)` のまま。補完によって学習データが10場になった状態を正とする）。

## Consequences

- walk-forward（5フォールドプール、4場のテストレース）: win_logloss −0.0045（CI [−0.0048, −0.0042]）・place_logloss −0.0129（CI [−0.0133, −0.0124]）・1位馬の的中率 +1.4pt（CI [+1.1pt, +1.8pt]）でいずれも有意に改善。標準 split でも同じ向きで有意（win_logloss −0.0051、place_logloss −0.0135、的中率 +1.6pt）。改善幅は過去に採用した特徴量（例: ADR-0030 の win_logloss −0.0008）の5〜10倍。
- 一方、1位馬の単勝を毎レース買う回収率は walk-forward で −2.8pt（82.1% → 79.2%、CI [−5.1pt, −0.7pt]）と**有意に悪化**し、5フォールドすべてで同じ向きだった（標準 split では −2.0pt、CI [−6.1pt, +2.0pt] で有意差なし）。確率の精度が上がって1位馬が人気馬（低オッズ）と一致しやすくなったためと推測されるが、未検証。
- それでも採用するのは、(1) 4場への絞り込みは意図しない設定ミスで、実際に予測する10場のレースのうち6場を学習データに一度も出さない状態は維持できない、(2) 「1位馬の単勝を毎レース買う」は回収率110%を狙う実際の戦略（EV で買い目を選ぶ）ではない、ため。回収率は EV 戦略側（三連複 EV ゲート等）で評価する。
- 過去の ADR の数値は4場データでのもの。個別の再検証はせず、今後の判定はすべて10場データで行う。単勝 EV のゲート（ADR-0029）と組合せ馬券の EV（ADR-0009）は、三連複 EV ゲートと合わせて10場データで測り直す。
