# ADR-0037: 「オッズあり」の三連複確率・3着内率は三連複オッズ（べき補正つき）から作る

- Status: Accepted
- Date: 2026-10-19

## Context

predict の「オッズあり」の三連複確率・3着内率は、単勝オッズから逆算した市場の勝率に2・3着の着順別ディスカウントをかけた Plackett-Luce で作っていた（ADR-0036 のフォローアップ、`dual_prediction.py`）。三連複の確定オッズ（`final_odds`）がそろったので、三連複オッズから直接逆算した確率（1/オッズ をレース内の全組で正規化）と、それを `q**alpha` で補正したものを比べた（`python -m predictor.main trio-market`。パラメータは較正期間 10,661レースで推定、テスト期間 21,424レース、レース単位ペアード bootstrap）。

## Decision

「オッズあり」の三連複確率と3着内率は、三連複オッズ（`q**alpha` で補正、alpha は較正期間で推定）から作る。勝率は単勝オッズのまま。発走前の三連複オッズが取れないときは、従来の「単勝オッズ + 着順別ディスカウント」で代用する。

## Consequences

- 三連複対数尤度: 単勝オッズ+ディスカウント 4.3205 に対し、三連複オッズ 4.2852（−0.035、CI [−0.040, −0.031]）、三連複オッズ+べき補正 4.2801（−0.040、CI [−0.045, −0.036]）でいずれも有意に改善。3着内率の logloss も −0.0025・−0.0031 で有意に改善。
- 推定値は alpha=1.06（1より大きい）で、三連複の市場でも人気薄の組がやや買われすぎている。
- どちらも締切後の確定オッズでの比較。predict では発走前のオッズを使うため、本番の精度は評価より少し落ちる。発走前の三連複オッズを使うため、predict のオッズ取得時に API の応答を `odds_snapshots` に発走前スナップショット（status=middle）として保存する。
- 検証の途中で、オッズ API が出走取消・競走除外・発売なしの組を「-3.0 / -2.0 / 0.0 倍・人気9999」で返し、それを数値として `final_odds` に保存していたことが分かった（23,242行）。保存時に0以下を除くよう修正し、既存行は削除した（生データは `odds_snapshots` に残る）。
