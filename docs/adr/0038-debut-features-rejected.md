# ADR-0038: 初出走・キャリアの浅い馬向けの特徴量（母の他の産駒・調教師/父のデビュー戦成績）を採用しない

- Status: Rejected
- Date: 2026-10-19

## Context

gap-analysis（`python -m predictor.main gap-analysis`）で、オッズなしのモデルと市場の差は新馬戦（勝率の対数尤度の差 0.374、平均の約1.4倍）と初出走の馬（3着内率の logloss の差 0.058、平均の約1.6倍）で最も大きかった。本人の成績が無くても使える身内・関係者の実績として、母の他の産駒の3着内率・出走数、調教師の管理馬と父の産駒のデビュー戦での3着内率（いずれも前日までのデータ、件数が少ないときは全体の率に縮小。`predictor/debut_features.py`）を P3（ADR-0036）に足し、テスト期間 21,443レースでレース単位ペアード bootstrap により比べた（`python -m predictor.main compare-debut`）。

## Decision

採用しない。

## Consequences

- 全体: 勝率 +0.0006（CI [−0.0006, +0.0019]）、3着内率 +0.0001（CI [−0.0001, +0.0003]）でいずれも有意差なし。
- 狙いの新馬戦（1,896レース）でも勝率 +0.0000（CI [−0.0037, +0.0037]）、初出走の馬（30,309頭）の3着内率 −0.0004（CI [−0.0009, +0.0000]）で有意差なし。
- 母・父・調教師の情報は、既存の血統の適性統計（ADR-0028）や調教師の成績の特徴量でほぼ表現できていたと考えられる。新馬戦で市場に負けている原因は、身内の実績ではなく、調教・パドックなど本人についての発走前の情報にあるとみられる（今のデータには無い）。
