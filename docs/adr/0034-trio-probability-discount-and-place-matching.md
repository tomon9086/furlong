# ADR-0034: 三連複確率の補正（着順別ディスカウント・複勝モデルとの整合）を採用しない

- Status: Rejected
- Date: 2026-10-16

## Context

三連複の確率は `win_prob` を Plackett-Luce に入れて出しており、2・3着の当たりやすさを直接最適化していない。改善案として、案A: 2・3着の強さを `p**lam2`, `p**lam3` に平らにする着順別ディスカウント（lam は較正期間で最尤推定）、案B: 各馬の3着内確率が複勝モデルの `place_prob` に一致するよう強さを調整する、を比べた。評価は Plackett-Luce の解析解（`predictor/trio.py`）で、テスト期間 21,443レース（10場、標準 split）の三連複対数尤度・3着内率の logloss・確率上位 N 点の回収率を、レース単位ペアード bootstrap で現行と比べた（`python -m predictor.main trio-baseline`）。

## Decision

案A・案Bとも三連複推奨には採用しない。三連複確率は当面、現行（`win_prob` → Plackett-Luce）のまま。

## Consequences

- 案A: 推定値は lam2=1.23・lam3=0.92 で、テスト期間では三連複対数尤度が +0.0055（CI [+0.0048, +0.0062]）と**有意に悪化**。3着内率の logloss も有意に悪化。
- 案B: 三連複対数尤度 −0.017（CI [−0.085, +0.021]）で有意差なし、3着内率の logloss は +0.0016（有意に悪化）。確率上位3点の回収率は +5.3pt（66.8% → 72.0%、CI [+0.9pt, +9.9pt]）だが、N=1/3/5 のうち1つだけの有意で、買い方は LLM 側の責務なので採否には使わない。
- 精度の伸びしろの目安として市場と比べた: 単勝の確定オッズから逆算した勝率を Plackett-Luce に入れた「市場」の三連複対数尤度は 4.36 で、モデル（4.84）より −0.48（CI [−0.55, −0.43]）良い。3着内率の logloss もモデル 0.457 に対し市場 0.420。オッズは特徴量に入れない方針（ADR-0001）なので市場に勝つことは目標ではないが、**3着内の精度には大きな伸びしろがある**。市場側は締切後の確定オッズで、発走前より有利な条件である点に注意。
- 市場の確率にはディスカウント（lam2=0.77・lam3=0.81）が効き、三連複対数尤度が −0.04 改善した（市場の Harville 推定は人気薄の2・3着を過小評価している）。
- フォローアップ: 市場との折衷は別の LLM が担うため、このモデルとしては「市場＋モデル」の検定や EV ゲート（`trio-ev`）は行わない。3着内の精度そのものを上げる方向（3着内を直接学習する目的関数など）を検討する。
