# ADR-0029: MC組合せ馬券展開のフェーズ2ゲート再検証（引き続きRejected）

- Status: Rejected
- Date: 2026-08-10

## Context

[ADR-0008](./0008-mc-win-prob-extension-deferred.md)（2026-05-27）で「単勝EVベット戦略が回収率100%を超えるか」をフェーズ2ゲートとして判定し、当時は65.9%止まりで組合せ馬券へのMC展開（フェーズ3）を見送った。その後 ADR-0012〜0028 で騎手・調教師・馬主の累積勝率、クラス変化、レース内ペース、スピード指数、血統適性統計など多数の特徴量が採用され、ベースモデルが当時より強化されたため、同じゲート判定を現行モデルで再実行した（`python -m predictor.main train`、標準split bootstrap CI + walk-forward 5フォールド プール bootstrap CI）。

## Decision

現行モデルでも単勝EV戦略は回収率100%を超えず、組合せ馬券（馬連・三連複・ワイド）への MC 展開（フェーズ3）には着手しない。ADR-0008 の判定を維持する。

## Consequences

- 標準split: 単勝EV閾値1.0〜3.0 × 全人気帯グリッドで、bootstrap CI が「有意に100%超」となるセルは0件（最良点推定は2-3番人気×EV≥2.0の85.9%、CI上限でも141%止まりで下限は39%）。
- walk-forward 5フォールド プール bootstrap CI（馬連・三連複・ワイド、EV閾値1.0〜2.5を0.1刻み）でも「有意>100%」は実質0件（ワイド1番人気の2セルのみTrueだが n=1 の退化例で無意味）。
- 特徴量追加によるベースモデルの精度改善は、単勝EVベットの回収率上限を実質的に押し上げていない。ボトルネックは引き続きベースモデルの市場に対するエッジ不足であり、MC はエッジを増幅するだけで生み出さないという [plan/ensemble-montecarlo.md](../plan/ensemble-montecarlo.md) の前提通りの結果。
- フォローアップ: 今後さらに特徴量・アンサンブルでベースモデルの精度を改善した場合は、同じゲート判定（`train` の標準split bootstrap CI 出力）を再実行して確認する。
